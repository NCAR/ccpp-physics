# Preview the documentation locally

The local build uses the same script as the GitHub Pages workflow.

## Create the environment

Create and activate the supplied Conda environment from the repository root, run the following from the `tools/doxygen` directory:

```sh
conda env create -f environment.yml
conda activate ccpp-physics-doxygen
```

If the environment already exists, update it with:

```sh
conda env update -f environment.yml --prune
```

The Conda file installs Python, Git, Make, Perl, TeX (including BibTeX), and
pins Doxygen and Graphviz to the versions used for the local preview. No
separate pip installation is needed.

To match the local rendering to a GitHub Pages deployment, open that workflow
run and find the **Show documentation tool versions** step. It reports the
Doxygen and Graphviz versions used by GitHub Actions; set the corresponding
versions in `environment.yml`, update the Conda environment, and rebuild.

## Build and view the pages

From the `tools/doxygen` directory, run:

```sh
make build
make host
```

The build checks out one ccpp-physics clone at each of these refs in turn:

| Make variable      | Repository                   | Default ref      | Sections                          |
|--------------------|------------------------------|------------------|-----------------------------------|
| `NCAR_PHYSICS_REF` | `NCAR/ccpp-physics`          | `main`           | HSD, GWv1, LandDA, landing page   |
| `V7_PHYSICS_REF`   | `NCAR/ccpp-physics`          | `v7.0.1`         | V7                                |
| `UFS_PHYSICS_REF`  | `ufs-community/ccpp-physics` | `release/srw-v3` | SRWv3                             |

Override any combination on the command line, for example:

```sh
make build \
  NCAR_PHYSICS_REF=my-physics-branch \
  V7_PHYSICS_REF=v7.0.1 \
  UFS_PHYSICS_REF=release/srw-v3
```

The Python entry point provides the equivalent `--ncar-physics-ref`,
`--v7-physics-ref`, and `--ufs-physics-ref` options. Each ref must contain the
Doxyfiles of the sections built from it (`ccpphsd_doxyfile`,
`ccppgw_doxyfile`, `ccpplandda_doxyfile`, and `mainpage_doxyfile`;
`ccpp_doxyfile`; `ccppsrw_doxyfile`), so a v7 release is not compatible with
the `NCAR_PHYSICS_REF` slot.

The metadata argument tables included by the documentation are generated by
`generate_metadata_html.py` in this directory, which reads the `.meta` files
of the checked-out Physics ref. No SCM or CCPP Framework checkout is needed.

Open <http://127.0.0.1:8000>. Press Ctrl-C to stop the server. The generated
site and temporary repository checkouts live under
`tools/doxygen/.build/doxygen/`; remove them with:

```sh
make clean
```

Use `PAGES_PORT=8080` or `PAGES_BIND=0.0.0.0` on the `make host` command to
override the server defaults.
